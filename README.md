# ChatApp
Java Chat App using spring boot and react.
This full-stack application enables real-time, instant messaging by combining a high-performance Spring Boot backend with a dynamic React frontend. It utilizes WebSockets and the STOMP protocol to provide low-latency communication, ensuring users receive messages instantly without page refreshes. The system features secure user authentication via JWT, persistent chat history stored in a database, and a responsive UI that manages live connection states. It’s a scalable solution perfect for both public chat rooms and private one-to-one conversations.
